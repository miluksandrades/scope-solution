# scope-solution

gerar um script python para realizar as seguintes tarefas:

- verificar a disponibilidade do SEI;
- verificar a disponibilidade do correio eletronico (Outlook);
- verificar a disponibilidade de internet (acessar qualquer site externo);
- enviar email com anexo do email pessoal para o institucional e vice versa;
- mostrar o relatorio dessas informações no final com OK ou FALHA;
- Gerar o PDF com prints de tela de cada verificação;
- A solução precisa abrir o browser Edge para validar os links.
